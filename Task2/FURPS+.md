| Код | Требования                         | Комментарий  |
|-----|------------------------------------|--------------|
| F   | **Функциональные (Functionality)**     |              |
| F1  | На сайте клиент видит список доступных депозитов с актуальными ставками 
| F2  | На сайте клиент  может подать заявку на депозит, оставив свой номер телефона и Ф. И. О                                 |              |
| F3  | В интернет-банке клиент видит список доступных депозитов с актуальными ставками и персонализированные ставки лично для него                                |              |
| F4  | В интернет-банке указав счёт и сумму депозита, клиент может подать заявку на открытие депозита                                |              |
| F5  | В интернет-банке операция подачи заявки на депозит подтверждается с помощтю СМС                                |              |
| F6  | На сайте клиент видит предложение открыть кредит по некоторой ставке 
| F7  | На сайте клиент может подать заявку на кредит, оставив свой номер телефона и Ф. И. О                                 |              |
| F8  | При указании паспортных данных, клиент сразу получает решение об одобрении или неодобрении ему кредита                                 |              |
| F9  | После подачи заявки клиенту приходит СМС о том, что нужно прийти в отделение для получения кредита и идентификации                                 |              |
| F10 | В интернет-банке клиент видит список доступных кредитов с актуальными условиями так же, как и на сайте.                                |              |
| F11 | В интернет-банке клиент может видеть предодобренное предложение по кредиту.                                |              |
| F12 | Менеджер может подать заявку на кредит через АБС                                 |              |
| F13 | В АБС есть возможность работы со ставками по депозитам для сотрудников бэк-офиса депозитов                               |              |
| F14 | В АБС есть возможность работы со ставками по депозитам для сотрудников бэк-офиса кредитов                                |              |
| U   | **Удобство использования (Usability)** |              |
| U1  | Интерфейс системы должен придерживаться дизайна приложений, который принят в компании                         |              |                                |              |
| U2  | Интерфейс системы должен быть оптимизирован под пользователей с плохим зрением  | Основная категория клиентов банка — люди старшего возраста             |                                |              |
| R   | **Надёжность (Reliability)**           |              |
| R1  | Данные с сайта необходимо защищать с помощью механизма шифрования трафика            |              |
| R1  | Данные из интернет-банка необходимо защищать с помощью механизма шифрования трафика  |              |
| R2  | Все сервисы должны работать 24/7 и быть доступны в 99,9% случаев                     |              |
| R3  | Наличие резервного ЦОДа, на который можно переключиться в случае сбоя                |              |
| P   | **Производительность (Performance)**   |              |
| P1  | Отклик по всем операциям должен занимать миллисекунды                                |              |
| S   | **Поддерживаемость (Supportability)**  |              |
| S1  | Должна быть поддержка интеграционного тестирования                                |              |
| S2  | Требуется документация в форматах Open API и Async API                                 |              |
| +R  | **+ Ограничения (Restrictions)**       |              |
| R1  | Использование базы данных MS SQL или Oracle                                |              |
| R2  | Новые технлогии должны быть совместимы с существующими платформами разработки                                |              |
| R3  | Наличие экспертизы внутри банка на уровне знания выбранных языков программирования                                |              |
| R4  | Использование Kafka для очередей сообщений 
| R5  | Не нужно нагружать базу АБС данными, которые ей не требуются для проведения операций менеджерами фронт- и бэк-офиса
| R6  | При разработке интернет-банка необхоодимо использовать микро-сервисную архитектуру
| R7  | Следует избегать прямого обмена данными между онлайн-банком и АБС, необходимо использовать шину данных (Kafka)
| R8  | Не дорабатывать функционал подрядчика в интернет-банке
